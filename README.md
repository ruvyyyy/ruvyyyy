## 🚀 Featured Projects

<details>
<summary><b>🛰️ Geospatial LST–NDVI–NDWI Analysis Pipeline</b></summary>
<br/>

Remote sensing research pipeline analyzing Land Surface Temperature, NDVI, and NDWI relationships across Karnataka using Landsat 8/9 and Sentinel-2 imagery processed through Google Earth Engine, spanning a 2015–2025 time series.

| Attribute | Detail |
|---|---|
| Stack | Python, Google Earth Engine, QGIS |
| Scale | 10-year multi-sensor time series, state-level AOI |
| Performance | Automated scene selection with cloud masking |
| Security | Read-only satellite data access, no PII |
| Impact | Research-grade climate/vegetation/water-index correlation study |
| Repository | [View Repo](https://github.com/ruvyyyy) |

Built with an emphasis on minimal manual input — automated scene selection, CRS-consistent reprojection, and cloud masking to keep outputs reliable across a decade of imagery.

</details>
